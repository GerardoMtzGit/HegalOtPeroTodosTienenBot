# HegalOT Pero Todos Tienen Bot 🤖✨

Cliente modificado de **HegalOT** con soporte completo de **vBot 4.8 / Tazo Dorado** y todas las funciones avanzadas restauradas de **OTClientV8 (Fresh)**.

## 🚀 Características incluidas y restauradas

- **vBot 4.8 completo** integrado de forma nativa (modules/game_bot).
- **Perfil predeterminado Tazo Dorado** con rutas personalizadas de CaveBot (Dark_Torturer, Roshamuul, alco, war_zona_lava, soul_hielo, etc.), AttackBot, HealBot y extensiones (levitate.lua).
- **CaveBot Editor en 2 columnas:** Interfaz del editor de waypoints organizada en dos columnas dinámicas y estéticas.
- **Auto Recording optimizado:** Grabación automática de waypoints al caminar, usar escaleras o interactuar con objetos en el mapa.
- **Terminal de Lua en el juego:** Accesible con Ctrl + T (modules/client_terminal).
- **Barras de salud y maná mejoradas:** (modules/game_healthbars).
- **Corrección de compatibilidad en Analyzer:** Compatibilidad para LuaJIT en el cálculo de tiempos.

## 📁 Instalación / Uso

1. Puedes clonar o descargar este repositorio:
   `ash
   git clone https://github.com/GerardoMtzGit/HegalOtPeroTodosTienenBot.git
   `
2. Ejecuta client.exe.
3. En el juego, abre la ventana del **Bot** (ícono en la barra superior).
4. Selecciona el perfil **Tazo Dorado** (o **vBot_4.8**) y actívalo (**On**).
